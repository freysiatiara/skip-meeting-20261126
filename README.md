## The line

> Sorry, I can't make the sync — my calendar and I are in couples therapy, and it just told me this meeting is the problem.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT`, or `$OUTPUT_DIR/entry.txt`).
